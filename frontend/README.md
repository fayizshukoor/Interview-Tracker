# Interview Tracker Frontend

This folder contains the React + TypeScript + Vite frontend for the Interview Tracker application.

## Tech stack

- React 19
- TypeScript
- Vite
- React Router
- Axios

## Main features

- Authentication screens and token handling
- Candidate management
- Question bank browsing
- Review creation and interview flow
- Review history and summary pages
- Dashboard views

## Scripts

- npm run dev — start the local development server
- npm run build — build the frontend for production
- npm run lint — run ESLint
- npm run preview — preview the production build

## Notes

The frontend expects the backend API to be running on port 3000. Authentication tokens are stored in browser local storage.
